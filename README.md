# Employee Salary Prediction

## Overview
This project is a Machine Learning based web application that predicts whether an employee belongs to a high-income or low-income category.

The model is trained using employee demographic and work-related attributes such as age, education, occupation, workclass, working hours, and capital gain.

The project uses Logistic Regression for prediction and Streamlit for building the web interface.
